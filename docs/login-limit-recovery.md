# ログイン試行制限の一度だけの解除

運営者が明示的に解除を依頼した場合に限り、Cloudflareのデプロイ設定 `QR_LOGIN_RESET_REVISION` に新しいUUIDを設定する。公開HTTPからこの値を指定する機能はない。

QRReceptionの次の起動時に `_qr_login_attempts` のカウンタだけをトランザクション内で削除し、`_qr_login_reset` にrevisionを記録する。同じrevisionで再起動しても解除を繰り返さない。パスワード、ユーザー、受付・出席・イベント・署名鍵・LINE Secretは変えない。誤ったパスワードは解除後も401。通常の10回/15分制限は維持する。

2026-10-24 JST、ユーザーの明示依頼で最小パッチを本番へ反映。更新前のWorkerソースSHA256は60cac2a1209a4e38a9c59077615ff9571ad784857286baeb453e2db25fe32972と一致。転送機能はこの更新に含めず、既存assetsは公式APIのkeep_assets:trueで保持。既存Secret名・DO namespace・assets binding・既存変数の一致と、配信後のソース完全一致を確認。配信後SHA256は97eb1663a82e54d5f84c01e9e56efbcac8a9d86503c07b93c857cec93bc30b21。

この環境はQRの公開ホストへのHTTP許可がないため、実ユーザーのカウンタ消去・ログイン成功は未確認。次のDOへのリクエスト（ログイン等）で一度だけ実行される。パスワードの一致を保証せず、設定値を推測したログイン試行はしない。QR本番のバックアップ取得に必要なAdmin認証情報は、このコード変更や他リポジトリの追加では得られない。
