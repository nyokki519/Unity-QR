# 受付に関係しないLINEメッセージは返信しない

受付用の完全一致キーワード（参加希望、参加QR、QR、QR再発行、参加確認、キャンセル）、有効な専用コード付きの参加希望/参加QR、既存のイベント選択ボタンに応答する。お礼、遅刻連絡、質問などの通常文章・スタンプ・画像・長文には返信しない。これらはLINEチャットで運営が確認する。

旧登録フローの名前入力待ちでも、通常文章を名前として登録しない。「名前：山田太郎」「名前 山田太郎」の明示形式だけを15分以内に受け付ける。入力依頼にもその形式を記載する。通常のフォーム申込コードによる本人紐づけ・QR受取・再発行・キャンセルは維持する。

無返信のWebhookは既存のignored状態で記録され、返信API・プロフィール取得を呼ばない。参加者・申込・受付履歴を変更しない。テストは架空データのみで、94単体/API＋7実workerd、型チェック・ビルド成功。本番への反映は既存バックアップ検証付きcloud:updateを使用する。
