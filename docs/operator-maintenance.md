# 一時的な運営者用の読み取り確認

QRへログインできない状況で、Cloudflareアカウント所有者がアカウント状態とバックアップを確認するための、既定OFFの保守処理。通常のユーザー認証を無効化せず、パスワード・ユーザー・受付データを書き換えない。

## 有効化の条件

- Cloudflareデプロイ側でのみ、ランダムな64桁hexの `QR_MAINTENANCE_TOKEN` をSecretへ登録する。公開リクエストから設定する経路はない。Gitやチャットに値を保存しない。
- `QR_MAINTENANCE_EXPIRES_AT`（UTC epoch millis）が必要。期限未設定・不正・期限切れ・現在から15分を超える期限は404。クライアントが中断しSecret削除に失敗しても権限を無期限に残さない。
- 保守APIはBearer完全一致とOriginチェックを行い、GET以外は受け付けない。トークンは通常の `/session` や `/backup` の認証には使えない。

## 読み取りの範囲

`GET /api/v2/maintenance/login-state` は固定のoperatorアカウントについて、存在・有効・Admin・保存ハッシュ形式が正常かの4つのbooleanだけを返す。ユーザー名、パスワード、ハッシュ、参加者情報、session tokenを返さない。パスワードの一致は推測せず、形式が正常でも入力との一致は証明しない。

`GET /api/v2/maintenance/backup` は従来のAdmin用と同じv4スナップショット。参加者情報・ユーザーのハッシュを含むため、所有者の非公開バックアップとして600権限のファイルに保存する。本文をログやチャットへ出力しない。メモリ上の別DBへの復元検証を行い、本番へimportしない。
