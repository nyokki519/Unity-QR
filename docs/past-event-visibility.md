# 過去イベントの表示

通常のイベント一覧と選択欄では、受付終了時刻を過ぎたイベントを非表示にする。「過去のイベントを表示」を選ぶと、過去の参加者・受付履歴も確認できる。表示の切替でデータ・権限・受付時間は変更しない。深夜までの受付は終了まで表示する。自動更新で選択イベントが隠れた場合、古い参加者・カメラを破棄して表示中のイベントへ切り替える。結果未確認の受付がある間は切替を保留する。

テスト・中止イベントは既存の管理者向け「削除・中止」で手動非表示・復元する。この操作はQR発行・受付も停止するため、確認画面を維持する。過去イベントを自動的にアーカイブ・削除しない。

Analyticsの受付画面には既に日付付きの過去表示切替があったため、受付終了時刻を境界にする修正だけを加える。受付終了時刻が欠損した旧データは、既存の日本時間の日付判定を維持する。

検証: 同日終了・終了時刻ぴったり・深夜継続・明示表示・履歴保持・通信結果未確認時の切替防止・小画面。API/DB/秘密情報/送信処理は変更しない。

公開はAnalyticsのGitHub/Vercel連携を使用。QRは所有者Macの既存cloud:updateでバックアップ・復元検証後に更新する。この環境にはCloudflare認証・管理者パスワード・既存公開設定がないため、保護を迂回して公開しない。
