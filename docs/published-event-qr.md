# 掲載イベントの受付自動準備

認証されたGoogle Form橋渡しが受理した申込は、公開イベントIDでも未作成の受付を自動準備する。開催日の日本時間0時〜翌0時、受理済みイベント名を使用し、同日の類似イベント候補は既存の保守的な判定で再利用する。複数候補、削除済み、日付不一致、終了済み、キャンセルは従来どおり拒否する。不正なsheet-event内部キーも拒否する。

専用コード付きの「参加QR」「参加希望」は同じ本人紐づけ・QR発行処理を使用する。コードなしの初回紐づけや任意文章からの本人推測は行わない。紐づけ後の両キーワードによる再発行は維持する。

既存データの変換・削除、スキーマ変更、秘密鍵変更はない。本番反映はMacの既存cloud:update（更新前DBバックアップ・復元検証付き）で行う。自動受付が未準備の受理済み申込は反映後に同じコード付きメッセージを再送できる。
